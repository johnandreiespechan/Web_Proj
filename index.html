About this project

A mock sales and inventory dashboard for a coffee shop with three branches. It uses only HTML, CSS and JavaScript. All data is sample data.

Data files

orders.csv has one row per order: order_id, date, branch, product, cups, unit_price, channel.

inventory.csv has one row per item per branch: item, branch, unit, stock_on_hand, reorder_level.

How the dashboard works

  1. The page loads both CSV files when it opens.
  2. The Branch and Timeline dropdowns decide which order rows are kept.
  3. The KPIs and charts are calculated from the kept rows.
  4. Changing a dropdown repeats steps 2 and 3.

Online orders are orders whose channel is GrabFood or foodpanda. To use your own data, replace the two CSV files and keep the same column names.
